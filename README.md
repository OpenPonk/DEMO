# OpenPonk: DEMO

[![Nightly](https://github.com/OpenPonk/DEMO/actions/workflows/nightly.yml/badge.svg)](https://github.com/OpenPonk/DEMO/actions/workflows/nightly.yml) [![Coverage Status](https://coveralls.io/repos/github/OpenPonk/DEMO/badge.svg?branch=main)](https://coveralls.io/github/OpenPonk/DEMO?branch=main)

[DEMO](https://ee-institute.org/demo/) (Design & Engineering Methodology for Organizations) diagram editor plugin for the [OpenPonk](https://openponk.org) modeling platform.

## Download

Download pre-built portable archives from [Releases](https://github.com/OpenPonk/DEMO/releases), or get the all-in-one build at [openponk.org/#download](https://openponk.org/#download).

## Installation

See [openponk.org/#direct-installation](https://openponk.org/#direct-installation) for the supported Pharo version.

```smalltalk
Metacello new
	baseline: 'OpenPonkDEMO';
	repository: 'github://OpenPonk/DEMO:main';
	load.
```
